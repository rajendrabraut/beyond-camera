# Beyond Camera 1.1.0.0

Covers everything since 1.0.1.0: full-resolution photos, scene-aware capture and Dual video.

## Downloads

- **BeyondCamera-1.1.0.0-release.apk** is the signed Android upgrade. It keeps the app ID and signing certificate. Captures and processing work offline.
- **BeyondCamera-1.1.0.0-diagnostics.apk** is the separately installed debug build (`com.beyond.camera.diagnostics`).
- **BeyondCamera-1.1.0.0-release.aab** is the Android App Bundle for store submission.

## What's new

- **Dual video.** Records the front and back cameras together in one video, with the second camera as picture-in-picture in the bottom-right corner. The switch button swaps which camera is the main one. Dual appears only on phones that can run both cameras at once (Android 11+ and supporting hardware). A remembered Dual mode falls back to Video on other phones.
- **Scene-aware capture.** The live view measures ISO, exposure, and blown-out and crushed areas, and classifies the scene as normal, low light or high contrast, with hysteresis so it does not flicker. With Smart processing on, Photo saves the instant shot, then merges the full-resolution still plus up to 2 more frames in dim light, or uses the HDR look in high-contrast scenes. Manual HDR wins. A small teal icon shows which is active.
- **Brighter dark video and photos.** In the dark, auto-exposure may lower the frame rate (lowest range topping at 30 fps) for a brighter, cleaner image. Not applied with manual Pro exposure or the phone maker's extensions.
- **Full-resolution photos.** Photo saves the instant preview frame at the tap, then swaps the sensor's full-resolution still into the same gallery file in the background (up to 6 pending; burst shots stay instant). Enhancement and crops run on the full-resolution still.
- **Instant and full-resolution capture in Pro and Portrait** too.

## Build and release

- CI fails if the release APK or bundle requests `INTERNET` or `ACCESS_NETWORK_STATE`.
- The release APK is ARM-only. The diagnostics build keeps x86 for emulator testing.

## Versions

- Android `1.1.0.0` (version code `11000000`).
- iOS marketing version `1.1.0`. The iOS app still covers photo and video capture only.
